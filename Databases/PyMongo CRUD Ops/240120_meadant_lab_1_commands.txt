What I wanted to do was find out how many Hyundai EV's were registered in the state of Washington and I wanted to find out the sums by their model. Here's the query I came up with:

db.EVs.aggregate([
    {
      $match: { Make: "HYUNDAI" }
    },
    {
      $group: {
        _id: "$Model",
        totalQuantity: { $sum: 1 } // Assuming you want to count the number of documents
      }
    }
  ])
